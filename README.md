## 关于这个仓库

这是我学习 AI Agent 基础设施方向的实战记录。  
方向是做 **AI Agent 时代的 API 网关**——不是 RAG，不是聊天机器人，而是让 Agent 连接工具、Agent 之间互相通信的基础设施。

每天自动追踪 MCP / A2A / LangChain4j / Spring AI 最新动态，记录在 [`daily-log/`](./daily-log/) 目录。

---

## 技术方向

```
MCP 协议    →  Agent 连接工具的标准（AI 时代的 REST API）
A2A 协议    →  Agent 之间通信的标准（AI 时代的 TCP/IP）
LangChain4j →  Java 生态 AI 框架
Spring Boot 3.x + Java 21 虚拟线程
Redis + Kafka + Docker + K8s
```

## 项目规划

- [ ] Phase 1：Java 21 + Spring Boot 3.x 地基
- [ ] Phase 2：中间件（Redis / Kafka / MySQL）
- [ ] Phase 3：LLM API + LangChain4j + Agent 基础
- [ ] Phase 4：GitHub MCP Server（手写 MCP 协议实现）
- [ ] Phase 5：AgentLink 多智能体协作网关
- [ ] Phase 6：Docker + K8s 部署上线
