# 技术日报 2026-05-21

## MCP / A2A 协议

- **MCP 生态已进入"基础设施化"阶段**：截至 2026 Q1，MCP 累计下载量超 9700 万次，Google、Microsoft 等大厂均已发布官方 MCP Server。mcpmarket.com 已做到每日更新 top server 排行榜，MCP 正在从"协议"变成"平台"。
- **A2A 协议实战落地加速**：Mastra 框架宣布原生支持 A2A 协议（@mastra/core@1.33.1），任何 A2A agent（包括 Google ADK、LangChain agent）均可通过 .well-known URL 互相发现和调用。MCP Mesh v2 也已支持 A2A，两个协议的互通正在成为现实。
- **四协议并存格局明确**：MCP（工具接入）、A2A（agent 间通信）、ACP（开放商务）、UCP（Google 商务层）各司其职。2026 企业级 agent 栈会同时使用这四个协议，而非选其一。

## LangChain4j / Spring AI

- **Devnexus 2026 对比演讲热议**：5 月 19 日发布的 "Spring AI vs LangChain4j" 演讲引发关注。两者均已 GA，均支持 MCP，但 LangChain4j 额外支持 A2A 且更新节奏更快；Spring AI 胜在原生 Spring 集成。
- **Spring I/O 2026 深度 MCP 集成**：4 月 Spring I/O 大会发布 "Deep dive into MCP with Spring AI" 专题，Spring AI 的 MCP 支持已从实验性变为一等公民。
- **Java AI agent 框架已有 6 个可用于生产**：CodeWiz 发布 2026 年 Java AI agent 框架实战对比，LangChain4j、Spring AI、Semantic Kernel、Google ADK Java 版等均已 GA，选型核心差异在 A2A 支持和 checkpointing 能力。

## AI Agent 方向

- **Google I/O '26 发布完整 agent 开发栈**：Managed Agents API（agent-as-a-service）+ ADK 2.0（复杂编排）+ Antigravity 2.0（本地开发），三层架构从低代码到全控制覆盖全场景。Managed Agents API 是本次 I/O 新发布的核心，提供 Linux sandbox、外网访问、按 token 付费。
- **Agent 框架排名格局**：LangGraph 以 9/10 评分领跑开源 agent 框架，PydanticAI 和 Google ADK 并列第二（8/10），CrewAI、OpenAI Agents SDK、Mastra 紧随其后。
- **Agent 信任问题浮出水面**：行业观察指出大多数 agent 产品在发布 2 周后出现信任崩塌——不是技术不行，而是一次自信的错误回答就会导致用户流失。这正在成为 agent 产品化的核心难题。

## 今日有趣 AI 产品

- **Google Gemini Omni Flash**：Google I/O 发布的新世界模型，能够进行高级 AI 视频生成，本质上是把 Gemini 从"理解世界"推向"生成世界"。
- **Google Managed Agents API**：一个 API 调用就能获得一个带 Linux sandbox 的自主 agent，自动推理、工具调用、网络访问全托管——把 agent 从"自己搭"变成"直接用"。

## 趋势小结

AI agent 方向正在从"框架百花齐放"转向"平台化+协议标准化"。Google I/O 2026 的信号非常明确：agent 开发正在分层（托管/框架/底层），协议互通（MCP+A2A）成为默认要求而非可选项。与此同时，Java 生态在 AI 方向的成熟度被严重低估——6 个 GA 框架、MCP/A2A 双支持、virtual threads 性能优势，Java 在企业 AI agent 领域的地位正在快速上升。正在降温的是"又一个 agent wrapper"类创业，正在升温的是 agent 可观测性、治理、持久化等"生产化"能力。
