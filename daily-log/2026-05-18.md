# 技术日报 2026-05-18

## MCP / A2A 协议

- **MCP 持续企业化落地**：Linux Foundation 发布 MCP 培训资源，微软发布 Azure DevOps 与 VS Code Agent 的 MCP 集成方案，MCP 已成为企业 AI 工程团队连接外部工具的事实标准。
- **A2A 协议 v1.0 稳定版已发布**：截至 2026 年 4 月，A2A 协议已有 150+ 生产组织采用、22K+ GitHub stars、5 种语言 SDK（Python/JS/Java/Go/.NET），并推出签名 Agent Cards 和 Agent Payments Protocol (AP2)。
- **MCP 与 A2A 定位清晰互补**：MCP 负责 Agent-to-Tool（连接数据源和 API），A2A 负责 Agent-to-Agent（跨框架/跨厂商的 Agent 协作），二者共同构成 AI Agent 基础通信层。

## LangChain4j / Spring AI

- **LangChain4j 1.0.0 正式发布**（5月14日）：核心模块达到 1.0 里程碑，新增 MCP 工具过滤、Kotlin 协程 Flow 支持、虚拟线程增强，后续模块将以 rc1 形式在 6 月发布。
- **Uber 4 个月烧完 2026 全年 AI 预算**：Forbes 报道 Uber 大规模使用 Claude Code，暴露了 token 定价模型对企业财务预算的冲击，侧面反映 AI 开发工具在企业中的爆发式采用。
- **Java AI 应用占比快速增长**：Azul 2026 年调查显示 62% 的企业使用 Java 构建 AI 应用（同比增长 12%），31% 受访者表示超过一半的 Java 应用包含 AI 功能。

## AI Agent 方向

- **Cloudflare + Stripe 推出 Agent 自主商务协议**：允许 AI Agent 自主创建云账户、购买域名、启动付费订阅，标志着 Agent 经济基础设施进入实用阶段。
- **Agentic AI 市场规模达 108 亿美元**：从 2025 年的 76 亿增长至 2026 年预估 108 亿，Gartner 预测 40% 企业将在核心流程中部署 Agent。
- **Runloop 成为 Agent 基础设施代表**：为企业提供安全开发、评估和规模化部署 AI Agent 的平台，获多家企业客户采用。

## 今日推荐关注

1. **Cloudflare + Stripe 的 Agent Commerce 协议**（InfoQ）—— AI Agent 开始拥有独立的商业行为能力，这是 Agent 经济的关键基础设施突破。
2. **LangChain4j 1.0.0 发布** —— Java 生态 AI 框架的里程碑，MCP 集成和虚拟线程支持使其成为企业级 Agent 开发的首选。
