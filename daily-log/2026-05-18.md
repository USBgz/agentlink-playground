# 技术日报 2026-05-18

## MCP / A2A 协议

- Thomson Reuters 与 Anthropic 扩展合作，通过 MCP 集成将 Claude 接入 CoCounsel 法律助手，MCP 在企业法律领域落地又进一步。
- DZone 发布 MCP vs A2A vs AG-UI 协议栈对比文章，AWS Bedrock AgentCore Runtime 已于 2026 年 3 月添加 AG-UI 支持，三大协议形成互补格局。
- A2A 协议安全实践指南发布，涵盖 AgentCards、mTLS、OAuth 签名卡片等认证方案，标志着 A2A 正从概念走向生产级安全落地。

## LangChain4j / Spring AI

- Spring AI 2.0 发布第六个里程碑版本（M6），持续推进 Java 生态的 AI 能力集成，详见 InfoQ Java 周报（5 月 4 日）。
- JDConf 2026 / JavaOne 2026 多场演讲聚焦 LangChain4j + Quarkus 的 Agentic 编排和 Spring AI 的 Agent 工作流构建。
- Azul 2026 Java 状态调查显示：62% 的企业已使用 Java 驱动 AI 应用（同比增长 12%），31% 的 Java 应用已包含 AI 功能。

## AI Agent 方向

- Agentic AI 在 2026 年 5 月达到关键拐点，从实验阶段全面进入生产部署，MSN 等多家媒体报道。
- 微软安全博客披露 Semantic Kernel 中两个 RCE 漏洞（CVE-2026-26030 / CVE-2026-25592），提醒 AI Agent 框架需重视安全审计。
- TGVP 发布《AI Agent Infrastructure in 2026》报告，指出 Agent 基础设施市场以 44-46% CAGR 增长，核心机会集中在有状态服务、模型无关中间件和治理基础设施三个方向。

## 今日推荐关注

- **微软 AI Agent 框架安全研究**：Semantic Kernel 的两个 CVE 揭示了当前 Agent 框架普遍存在的执行层安全隐患，建议所有使用 Agent 框架的团队排查类似风险。详见 [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/05/07/prompts-become-shells-rce-vulnerabilities-ai-agent-frameworks/)。
- **TGVP Agent 基础设施报告**：四层架构分析 + 三大投资信号，是理解当前 Agent Infra 全景的优质参考。详见 [TGVP Report](https://www.tgvp.vc/releases/tgvp-report-ai-agent-infrastructure-in-2026)。
