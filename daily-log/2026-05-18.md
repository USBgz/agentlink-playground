# 技术日报 2026-05-18

## MCP / A2A 协议

- **MCP 安全危机持续发酵**：4 月 OX Security 披露 MCP 协议存在架构级漏洞（14 个 CVE），影响超 20 万台 AI 服务器，可导致远程代码执行。核心问题是 STDIO 传输层缺乏原生隔离——这不是 bug，是设计选择。Anthropic 将其归类为"预期行为"，引发社区对安全与互操作性之间根本矛盾的讨论。
- **A2A 协议已归入 Linux Foundation**：Google 发起的 Agent-to-Agent 协议于 2025 年 6 月捐赠给 Linux Foundation，目前定位清晰——MCP 管"Agent 连工具"，A2A 管"Agent 之间对话"。ADK（Agent Development Kit）已提供完整 A2A 集成，支持 Agent Card 发现、OAuth 2.0 认证和有状态任务委派。
- **NIST 正式介入 Agent 身份治理**：2 月启动 AI Agent Standards Initiative，核心提案是将 AI Agent 视为"Non-Human Identity"（NHI），适用现有 OAuth/OIDC/SPIFFE 框架。EU AI Act 同步要求高风险 AI 系统记录 Agent 行为日志。监管框架正在成形。

## LangChain4j / Spring AI

- **LangChain4j 升至 1.15.0**：新增 `langchain4j-google-genai` 集成模块。Quarkus 侧 1.9.x 持续发力，三个新扩展让 Java 架构师在企业级 Agent 开发上有了更多选择。社区活跃度保持高位，GitHub issue 修复节奏稳定。
- **Spring AI MCP 进入 2.0 里程碑**：`spring-ai-mcp` 已推进到 2.0.0-M2（2026 年 1 月发布）。Spring Boot 3 + MCP Server 的组合让 Java 团队可以一次构建、多端兼容（Claude Desktop、VS Code、Cursor、Gemini CLI）。SSE vs STDIO 传输选择是主要坑点。
- **JavaOne 2026 大量 AI Agent 议题**：包括"Building Agents with Spring AI and Amazon Bedrock"和"Developing an Asynchronous Application with Virtual Threads and Structured Concurrency"。Java 21 虚拟线程 + AI Agent 已成主流组合，Azul 调查显示 62% 企业正用 Java 驱动 AI 应用。

## AI Agent 方向

- **Gartner 预测：到 2026 年底 40% 企业应用将嵌入任务型 AI Agent**（2025 年不足 5%）。Agent 正在从实验品变成基础设施。Adopt AI、CrewAI、LangGraph 等多 Agent 框架竞争进入白热化。
- **Agent 身份成为新的安全前沿**：NIST 将 Agent 身份管理列为优先标准领域。SpruceID 等数字身份公司已提交正式意见，主张用可验证凭证（Verifiable Credentials）来管理 Agent 的委托授权。这是一个全新的基础设施层。
- **RSAC 2026 上 Splunk 发布 6 个安全专用 AI Agent**：覆盖检测构建、恶意软件逆向、引导式响应等场景。Darktrace 报告称 76% 安全专业人员对 AI Agent 感到担忧，但只有 37% 有相应策略——安全领域的 Agent 化在加速，但治理远远落后。

## 今日有趣 AI 产品

- **Hint（Martha Stewart 联合创办）**：AI 家庭管理助手，能在问题发生前提醒你——比如浇灌地基防止干裂、提前续保险、识别不值得请承包商的小问题。解决的是"家庭维护靠记忆和运气"这个普遍痛点，用 AI 替代传统高成本的管家服务。
- **mysoft.ai**：5 月 16 日在 Product Hunt 上线的中立 AI 工具市场，17 个品类、18 个初始商品。不绑定任何生态，任何技术栈的开发者都可以上架。试图解决 AI 工具分散、发现困难的问题。

## 趋势小结

AI 行业正在经历从"模型能力竞赛"到"基础设施与治理竞赛"的转向。MCP 的安全漏洞、NIST 的身份标准提案、EU AI Act 的合规要求，三件事指向同一个结论：Agent 大规模部署的瓶颈不再是能力，而是信任和安全。与此同时，Java 生态（Spring AI + LangChain4j）在企业 Agent 开发中的地位持续巩固，虚拟线程让 Java 在高并发 Agent 场景下的表现更有竞争力。降温的是纯粹的"AI wrapper"产品——Hint 这类有领域深度的 AI 应用正在替代它们。

## 今日推荐关注

- **MCP 安全漏洞事件全貌**：14 个 CVE、20 万台服务器受影响、Anthropic 称"预期行为"——这不是一个普通安全事件，而是整个 Agent 互联架构的设计取舍被摊开讨论。如果你在用 MCP 构建任何东西，必须了解 STDIO 传输的风险边界和缓解方案。
- **NIST AI Agent Standards Initiative**：这是美国联邦政府首次系统性地为 AI Agent 制定身份、安全和治理标准。其三大支柱（互操作性、安全、身份）将直接影响未来 Agent 产品的合规要求。现在了解，比被动应对要好得多。
