# 技术日报 2026-05-23

## MCP / A2A 协议

- **MCP 2026-07-28 规范候选版发布**：这是 MCP 自发布以来最大的一次协议修订，交付了 2026 路线图中的无状态化等关键特性。Python SDK 月下载量已达 1.64 亿，公共注册中心索引超过 17,000 个 MCP 服务器。
- **Google I/O 2026 全面押注 MCP**：Google 正式将 MCP 作为 Agent-to-Tool 的通用协议标准，结合 A2A 用于 Agent 间协作。完整企业 Agent 栈的共识已形成：MCP 管工具接入，A2A 管 Agent 协调，ACP/UCP 管商务交易。
- **协议生态从"选择"变为"分层"**：2026 年中的格局已经清晰——不是 MCP vs A2A 的竞争，而是 MCP + A2A + AG-UI 等多层协议栈的组合使用。67% 的 CTO 表示 MCP 将在 12 个月内成为其默认集成标准。

## LangChain4j / Spring AI

- **Spring AI 2.0.0-M5 发布（4月底）**：新增 Anthropic 原生 Web 搜索工具集成、OpenAI SDK 音频转录支持、地理数据驻留等功能。Spring AI 正在从"实验性框架"走向全功能企业级 AI 平台。
- **LangChain4j 1.14 GA，A2A 支持领先**：在 Java AI Agent 框架横评中，LangChain4j 是目前唯一同时支持 MCP 和 A2A 的 Java 框架。Spring AI 则凭借原生 Spring 生态和自动配置保持"开箱即用"优势。
- **Devnexus 2026 大量 Java AI 议题**：Josh Long & James Ward 演示了用 Spring AI 构建 MCP-enabled 系统；另有专题讲解如何用 MCP 将遗留 Java 单体改造为 AI Agent，无需重写。

## AI Agent 方向

- **Google Managed Agents API 正式发布**：一行 API 调用即可启动一个具备推理、工具调用和代码执行能力的 Agent，运行在隔离 Linux 环境中。这是"Agent 即服务"模式的标志性产品。
- **Context Engineering 成为核心瓶颈**：Manus 团队分享经验——Agent 基础设施的真正成本不在 Agent 逻辑本身，而在运行时、记忆、上下文管理、可观测性和治理层。他们将手动调优过程称为"随机梯度下降"。
- **Google 搜索全面 Agent 化**：AI Mode 全球上线，支持 Agent 式预订（餐厅、KTV 等），直接在搜索中完成复杂多步任务。Personal Intelligence 扩展至 200 个国家。

## 今日有趣 AI 产品

- **Clawvisor（YC P2026）**：让 AI Agent 使用 Gmail/Slack/Google Drive 等应用时，永远不会接触到你的凭证——解决了 Agent 安全代理操作的信任问题。
- **Google Pics**：Google I/O 发布的 AI 设计工具，直接对标 Canva 和 Claude Design，集成在 Workspace 中，主打企业内部快速生成视觉内容。

## 趋势小结

Agent 基础设施正在从"能不能跑"转向"怎么治理"。本周 Google I/O 和 MCP 新规范候选版同时落地，信号非常一致：协议层已经收敛（MCP+A2A 成为事实标准），竞争焦点转移到 Agent 运行时的可控性和可观测性上。Java 生态在 AI 方向的投入明显加速，Spring AI 2.0 和 LangChain4j 的成熟让企业不再需要为了做 AI 而迁移到 Python。降温的是"造新协议"的热情——行业已经在整合。

## 今日推荐关注

- **Manus 团队的 Context Engineering 博文**：真正做过 production Agent 的团队分享的经验教训，比大部分教程都有价值——核心观点是"上下文管理才是 Agent 的真正瓶颈"，值得所有做 Agent 基础设施的人读。
