# 技术日报 2026-05-23

## MCP / A2A 协议

- **MCP 规范新版本发布候选**：MCP 2026-07-28 规范 Release Candidate 已公开，持续完善协议标准化。截至 2026 Q1，Google、Microsoft 等大厂已发布官方 MCP 服务器，生态下载量突破 9700 万次。
- **A2A 协议生态扩大**：Google 主导的 A2A 协议已吸引 50+ 合作伙伴，于 2025 年 6 月捐赠给 Linux Foundation 进行中立治理。Rust 实现的 A2A Agent 已可部署到 Google Cloud Run。
- **协议格局趋于收敛**：行业观察者将 MCP（工具连接）、A2A（Agent 间通信）、AG-UI（用户界面）视为核心三层协议栈，其余协议（ACP、UCP、X42）影响力有限。

## LangChain4j / Spring AI

- **Spring AI 今日发布 1.0.8 / 1.1.7 / 2.0.0-M7**：包含 CVE-2026-41863 安全修复。Spring AI 2.0 持续强化 MCP 支持和 Agentic Workflow 能力。
- **Spring I/O 2026 Keynote 重点**：推荐直接迁移到 JDK 25，Spring AI 2.0 全面支持 MCP、agentic workflows，Virtual Threads + Structured Concurrency 成为推荐并发方案。
- **JVM 多 Agent 编排讨论升温**：有文章讨论"何时该离开 Spring AI"，指出对于复杂多 Agent 编排场景，专用框架（如 Temporal + Spring AI 组合）可能更合适。

## AI Agent 方向

- **Google I/O 2026 全面 Agent 化**：发布 Gemini 3.5 Flash、Antigravity 2.0 (agentic 开发平台)、Managed Agents API（一个 API 调用启动一个 Agent）、Gemini Spark（24/7 个人 AI Agent）。Google 的战略从"prompts to action"明确转向 Agent。
- **Agent 安全成为学术热点**：MIT 6.566 课程（Spring 2026）专门开设 AI Agent Security 方向，说明安全问题已经从边缘进入主流学术视野。
- **Transactional Agent Workflows**：业界开始用 Temporal + Spring AI 构建带事务保障的 Agent 工作流，Agent 不再只是聊天，而是在执行真实的金融交易和业务操作。

## 今日有趣 AI 产品

- **OpenAI "AI Phone"**：OpenAI 联手 Jony Ive 团队打造 AI-first 硬件设备，不是智能手机升级而是重新定义人机交互界面。预计使用台积电 2nm 工艺 MediaTek SoC，2027 年量产。这是第一次有大模型公司认真做消费硬件。
- **Google Search Agents**：Google 搜索中嵌入 Agentic Booking 功能，可以帮你搜集实时价格和可用性并直接链接到预订——搜索引擎正在变成执行引擎。

## 趋势小结

AI 行业本周的关键词是 **"Agent 落地基础设施化"**。Google I/O 把 Agent 从概念推到了平台级产品（Managed Agents API 一行代码启动 Agent），Spring AI 在 Java 生态同步跟进 MCP 和 Agent 支持。协议层的竞争已经基本结束——MCP + A2A 双协议格局已定，剩下的是谁能把 Agent 真正跑在生产环境里。降温的是"模型能力竞赛"叙事（Meta Avocado 延期、考虑临时用 Gemini 说明单靠模型已不够），升温的是 Agent 的可靠性工程（事务、安全、可观测性）。

## 今日推荐关注

- **Spring AI 2.0.0-M7 + Spring I/O Keynote**：如果你在 Java 生态做 AI 应用，这是最重要的一周。MCP 原生支持、Agentic Workflow、JDK 25 推荐迁移路径都在这里定调。值得看 Keynote 视频了解全貌。
- **Google Managed Agents API**：一个 API 调用就能启动一个具备推理、工具使用和代码执行能力的 Agent，运行在隔离 Linux 环境中。这可能是 2026 年 Agent 基础设施最重要的产品化动作，值得深入研究其架构和限制。
