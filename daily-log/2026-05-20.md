# 技术日报 2026-05-20

## MCP / A2A 协议

- **Google I/O 2026 推出 WebMCP**：Chrome 团队发布 WebMCP 标准，让 AI agent 可以通过标准化协议与网页交互，配合 "auto browse" 功能打造 agentic web 体验。这是 MCP 从开发者工具走向终端用户浏览器的关键一步。
- **Google AI Edge Gallery 支持 MCP over Streamable HTTP**：Google 在移动端 AI 应用中实验性集成 MCP，支持 on-device 模型通过 MCP URL 动态导入工具定义，将 agent 能力推到边缘设备。
- **A2A 协议已进入 150+ 企业生产环境**：据 Google I/O 2026 披露，A2A 协议在企业侧的采用速度超预期。Morgan Stanley 已展示 MCP + A2A 协同运行的实际架例，API 部署周期从两年压缩到两周。

## LangChain4j / Spring AI

- **LangChain4j 1.15.0 正式发布（5月11日周报确认）**：新增功能包含 bug 修复、依赖升级和新 feature，生态持续活跃。社区项目 langchain4j-aideepin 同步更新至 3.25.2。
- **Devnexus 2026 大量相关演讲上线**：包括 "Choose Your Fighter: Spring AI vs LangChain4j"（对比选型）、"Building AI Agents with Spring & MCP"（Josh Long & James Ward），以及 "From Monolith to AI Agent: Modernizing Java Systems with MCP"。Java 社区对 AI agent 化的兴趣明显升温。
- **Agentic Design Patterns 实践浮现**：Guillaume Laforge（5月18日）发布了基于 LangChain4j 和 Google ADK 的 Agentic Design Patterns 演讲内容，标志着 Java 生态中 agent 设计模式正在从概念走向工程实践。

## AI Agent 方向

- **Google I/O 2026 全面押注 Agent**：Sundar Pichai 明确 2026 目标是把 AI agent 推到所有核心服务（Search、Gmail、YouTube、Docs、Chrome）。发布 Antigravity 平台升级，定位为 agent-first 开发平台。
- **TrueFoundry 发布 Skills Registry + OAuth MCP 方案**：解决了两个 agent 生产化的关键痛点——技能复用（Reusable Agent Skills）和企业级 token 管理（OAuth at MCP Layer），5月15日发布。
- **中国 AI agent 治理框架出台**：中国在 2026 年 5 月发布 AI agent 专门监管框架，与欧盟、美国形成三种不同的治理路径。这对在中国市场部署 agent 的团队是必须关注的合规信号。

## 今日有趣 AI 产品

- **Google Gemini Omni**：世界模型 + AI 视频生成能力，能理解并生成物理世界视频内容。不是又一个聊天机器人，而是朝 "理解世界运行规则" 走了一步。
- **Limrun（YC P2026）**：解决云端 coding agent 无法使用 XCode/Android Emulator/Unity 等原生开发工具的问题，为需要本地能力的团队提供 cloud coding agent 方案。

## 趋势小结

本周最大事件是 Google I/O 2026，信号非常明确：**Agent 不再是 demo，而是产品**。Google 将 agent 嵌入搜索、浏览器、办公套件，标志着 agent 从开发者玩具进入消费者产品阶段。与此同时，MCP 正在跨越协议阶段进入平台阶段——WebMCP、边缘设备 MCP、OAuth for MCP 都说明基础设施层在快速补齐。降温的是纯粹的"对话式 AI"叙事，升温的是 agent + 工具 + 协议的系统性工程思维。

## 今日推荐关注

- **Chrome WebMCP + "15 updates for the agentic web"**（developer.chrome.com/blog/chrome-at-io26）：如果你在做 agent 产品，Chrome 团队对 agentic web 的定义和标准制定会直接影响未来 agent 如何与 web 交互。值得通读。
- **TrueFoundry "OAuth at the MCP Layer" 博文**（truefoundry.com，5月15日）：企业落地 MCP agent 最头疼的就是 token 管理和权限控制，这篇给了一个可参考的工程方案。
