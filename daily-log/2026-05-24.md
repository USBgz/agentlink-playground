# 技术日报 2026-05-24

## MCP / A2A 协议

- **MCP 生态持续扩张**：Morgan Stanley 在 QCon London 2026 演示了基于 MCP + FINOS CALM 重构 API 治理体系的实践，API 首次部署时间从两年压缩至两周。Pinterest 内部也围绕 MCP 构建了覆盖 Presto、Spark、Airflow 的领域级 MCP 服务器生态，MCP 正从"协议标准"演变为企业内部 API 网关的替代方向。
- **A2A 进入 v1.0 稳定版**：Google 主导的 A2A 协议在 2026 年 4 月发布 v1.0 stable，新增 signed Agent Cards（可验证身份的 Agent 名片）和 Agent Payments Protocol（AP2），同时获得 Microsoft Copilot Studio、Azure AI Foundry 和 Amazon Bedrock 的原生支持。A2A 现已移交 Linux Foundation 治理。
- **A2A Java SDK 1.0 首个 Beta 发布**：InfoQ 4 月 27 日 Java 周报确认 A2A Java SDK 1.0 beta 1 已发布，Java 生态正式进入 A2A 多 Agent 互联轨道。MCP 与 A2A 的定位已逐渐清晰：MCP 管 Agent 与工具/资源的连接，A2A 管 Agent 与 Agent 之间的协作。

## LangChain4j / Spring AI

- **LangChain4j 1.14.0 发布**：本次为正式版与第 24 个 Beta 并行，带来 bug 修复、依赖升级及新功能。1.x 系列 API 趋于稳定，且已同时支持 MCP 和 A2A，是目前 Java Agent 框架中互操性最完整的选项。在 Devoxx France 2026 上，LangChain4j 被作为演示 Agentic Design Patterns 的主力框架。
- **Spring AI 进入 2.0 里程碑阶段**：Spring AI 2.0-M5（第五个里程碑版本）正在推进中，同期 Spring AI 1.0.7 / 1.1.6 安全补丁已发布，修复了 5 个 CVE，其中 2 个高危漏洞涉及 VectorStore 过滤表达式注入和跨租户内存数据泄漏——提示向量存储集成的安全边界还需要更多规范化。
- **Java AI 框架竞争格局成型**：LangChain4j、Spring AI、Semantic Kernel、Google ADK for Java 四框架并立，差异化已经显现：Spring AI 与 Spring Boot 原生整合最优，LangChain4j 对 MCP/A2A 支持最全，ADK 更适合 Google 生态的多 Agent 编排。"选哪个"开始取代"用不用" 成为团队真正的问题。

## AI Agent 方向

- **Microsoft Build 2026（6 月 2-3 日）聚焦 Agent 可靠性**：微软将大会搬回旧金山（近十年首次），主题不是模型演示，而是让 Agent 和 AI 应用足够坚固以撑起企业使用。重点议题包括 Agentic RAG 架构、Azure Foundry IQ（为 Agent 提供上下文管理）、AI 治理与可观测性。微软公开表示，下一阶段的竞争将由基础设施胜负决定，而非模型本身。
- **YC P2026 批次中 Agent 主题占主导**：YC 最新一批（P2026）AI 创业公司中，Agent 方向占压倒性多数：flowscope（用 Agent 记录企业业务流程）、Korso（制造业运营 Agent 自动处理 RFQ 和供应商协调）、Kuli（社交媒体和 KOL 营销 Agent）等，行业渗透正在从软件工具转向业务运营替代。
- **AI 基础设施层加速标准化**：Uber 在 JavaOne 2026 演示了从 Java 运行 GPU 加速 AI 推理的生产实践（2 万个模型/月训练量，530 万模型在生产中）；Java 25 LTS 的虚拟线程和 Java 26 的结构化并发正被用于构建高并发 AI 推理服务端，Java 企业生态在 AI 基础设施层的渗透速度超出预期。

## 今日有趣 AI 产品

- **NeuBird（AI SRE）**：微软 Build 2026 入选创业公司，用 AI Agent 替代人工处理告警和运维响应，2025 年已帮助客户处理 23 万条告警、节省 1.2 万工程小时——解决的是"告警太多、工程师看不过来"的老问题，但规模化数据说明已跨越 demo 阶段。

## 趋势小结

当前 AI 方向的核心转变是：**从"能不能用" 转向"怎么用得住"**。MCP/A2A 协议正在取代临时集成方案成为 Agent 互联的基础设施规范；企业侧的关注点从功能演示转向可观测性、安全合规和长期维护成本。Java 生态的意外崛起值得重点关注——凭借 Spring Boot 成熟体系和虚拟线程并发能力，它正在抢占 Python 在企业 AI 工程化中的份额。降温的是纯 RAG 管道类产品，正在变热的是有明确业务替代价值的垂直 Agent（运维、制造、销售运营）。
